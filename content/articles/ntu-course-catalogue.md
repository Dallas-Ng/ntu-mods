## How to search the catalogue

1. **By code prefix** — most module codes start with a 2–4 letter prefix tied to the offering school (e.g. `AB` for Accountancy & Business, `CV` for Civil Engineering). Type the prefix into the [Module Browser](/mods) search box.
2. **By school filter** — use the faculty links in the table above, or the faculty dropdown on the [Module Browser](/mods) itself.
3. **By topic** — search by keyword (e.g. "machine learning", "marketing", "structures") to find modules across schools that match a subject, not just a code.
4. **By AU or level** — group results by AU or module level using the sort options on the [Module Browser](/mods).

Every module page shows prerequisites, exclusions, mutually exclusive modules, index timeslots, venues, and the exam date for the current semester. Add any module to your [timetable](/timetable) to check for clashes before your STARS registration window opens.

## Frequently asked questions

### How many modules does NTU offer in total?

NTUMods shows approximately 1,139 module offerings across all schools for AY2026/2027 Semester 1. This count changes each semester — check the [Module Browser](/mods) for the current live total.

### How do I find which school offers a specific module code?

Module code prefixes map to schools — for example `AB`/`BF` for Business, `CV` for Civil Engineering, `EE`/`IE` for Electrical & Electronic Engineering, `MA` for Mechanical & Aerospace Engineering. Search the code directly on the [Module Browser](/mods) to see its full details including which school offers it.

### Does the catalogue include postgraduate modules?

Yes — modules at all levels (undergraduate core, electives, and postgraduate-crossover modules commonly taken as advanced electives) appear in the same catalogue and are filterable on the [Module Browser](/mods).
